## Where Q28's theme comes from

Q27 asked that every fact the tree already derives be read by something, and by its own account it
succeeded: bounds that name a gap now carry a row saying whether anything reads it, a shared parse
has no private copies left, citations that name a unit resolve, the founder's page renders what its
own documents can be made to say, and seventy-one derivations the product computes for nobody are
named with the screen that would ask. W350 re-reads the claim list and is in flight in a sibling
session as this is written; nothing below depends on its verdict, because what Q28 comes from is
not whether Q27 met its gate but what the quarter kept finding on the way — including in its own
builders' first attempts.

**Every defect Q27 found failed toward looking correct.** Not one of them announced itself.

**W345 found a bound that was false from the day it was written.** `page-reach.ts` stated that a
route added inside an existing class's directory inherits that class's allowance *without anybody
deciding it should*. Planting one returns it as `unclassified`: the classes name their routes, and
adding a route to a class is exactly somebody deciding. The sentence had never been true — and it
sat behind `NOT_CALLABLE`, a shared excuse saying no witness could be handed to the detector, which
was itself false. **An unfalsifiable excuse is where a false claim goes to be safe.**

**W340's first derivation reported thirty-five and the answer was seventy-one.** It counted a
reader as any file whose text contains the export's name, so `readEvidence` had a "reader" because
a probe string names it and `guidelineIntervals` had one because a fixture mentions it. Prose about
a function is not a call. The error moved the number **down** — fewer unread facts, a healthier
tree — and would have shipped as the more comfortable figure.

**W349's population failed open, and the register had already written the failure down.**
`quarterModules(root, 326, 338)` in the pre-W342 shape dropped its extra arguments, every
comparison went false, and the function returned **the whole tree — 295 source modules on the day** rather than the quarter's
eleven. Nothing threw. W343 had found exactly this and W342 had fixed the signature; the
mis-call reproduced the register's own documented failure mode from outside it, and a population
that fails open looks like a *bigger* answer rather than an error.

**W349 also found a survivor whose remedy had been written and never applied.** `controls.ts`'s
`pending` lookup is the mutant W332 recorded in `claim-classes.ts`, whose fix it described in the
register and left for W331 — which did not apply it. W337 then wrote `controls.ts` on the same
pattern and the hole arrived with it. A recorded remedy nobody applies reads exactly like a solved
problem.

**W346's premise was wrong for three pages of four until something drove it**, and the walk that
proved it passed alone and failed inside the full suite — reading another spec's state, and
agreeing with itself either way.

**And W335's finding one quarter earlier was the same shape**: a document and its own test sharing
a private parse, both saying sixteen where the tree said eighteen. The smaller number. The one
nobody queries.

The common shape is not that these checks were absent. It is that **each one's failure mode was to
look correct** — a superset returned instead of an error, a count moving toward comfort, an excuse
that cannot be contradicted, a remedy recorded as though recording it were the fix. A check that
fails loudly is worth less than it appears if the way it actually breaks is quietly.

So: **Q28 — which way it fails.** Every unit takes a check, a derivation or a declaration in this
tree and establishes which direction its failure moves in — and where that direction is *toward
looking correct*, makes it loud instead. The gate follows Q25's, Q26's and Q27's shape rather than
a number, because Q24's was a number and the number measured the wrong thing: the gate is that
**every check this document names either declares its failure direction or is shown failing
loudly**, and W363 re-reads the list.

Nothing here needs a ruling; nothing adds a blocked row.

## What this document deliberately does not do

- **It does not plan Q29 or Year 8.** Requirement 1, and W208's receipt for the cost of planning
  four years ahead.
- **It does not set a numeric gate.** Q24's was a number, the number moved the wrong way, and that
  quarter's own note says the instrument rather than the work was wrong. Q25, Q26 and Q27 each
  refused a number and each gate worked; repeating what works is not novelty for its own sake.
- **It does not claim Q27 failed.** Q27's units all landed and its findings are real. The defects
  quoted above are the quarter's own work finding them — three of the five are a Q27 builder's
  first attempt, caught by driving it. That is the process working, and it is also the evidence
  that the failure direction is worth a quarter.
- **It does not propose an eleventh gate.** Q28 crosses none.
- **It does not rank the outstanding decisions.** W257 declined; the two orders that fall out of
  its tables disagree, and it is the founder's call.
- **It does not treat a builder's wrong first answer as a defect in the unit.** W340 shipped
  seventy-one because it drove the scan; W349 shipped eleven because it drove the population. What
  the theme is about is that neither wrong answer would have looked wrong.
